Setup guide

Get your first store ready.

Follow these steps in order. Provider-specific configuration is supplied by the connector you install.

  1. Install prerequisites

    Install eCommerce Integration Core and OCA queue_job. Configure a working queue runner. Queue Job source: https://github.com/OCA/queue

  2. Install a provider connector

    Install a compatible connector for the external platform you want to integrate. Core alone does not call external APIs. For Magento, get Magento Connector for Odoo here:
    https://apps.odoo.com/apps/modules/19.0/odoo_ecommerce_magento

  3. Create an Instance

    Open eCommerce / Configuration / Instances. Enter provider details, company, credentials and queue user. Run Test Connection where supported.

  4. Create and configure a Store

    Open eCommerce / Configuration / Stores. Select the Instance and external store scope, then configure warehouse, currency and automation settings.

  5. Set scheduling and permissions

    Configure resource intervals and batch sizes in the Scheduling tab. Assign appropriate eCommerce access groups.

  6. Prepare mappings and initial sync

    Set up connector-required mappings. Start with supported categories and products, then customers and orders as applicable.

  7. Monitor jobs and issues

    Review Monitoring / Queue Jobs, Synchronization Issues and Synchronization States. Resolve errors before enabling routine processing.

Before installation

Requirements and boundaries.

Odoo dependencies

Base, Mail, Sales Management, Inventory, Accounting, Delivery, Website Sale and OCA queue_job.

Queue runner

A working OCA queue_job runner is required for background synchronization.

https://github.com/OCA/queue

Provider connector

Install a compatible provider connector for Magento or another platform. The Core does not include a provider API client.

Scope note: External API operations, platform-specific mappings and workflows depend on the connector. Core does not provide standalone webhooks, RMA processing or external API integration.

Frequently asked questions

Good to know.

Can Core connect to an eCommerce platform by itself?

No. Core provides shared Odoo models, mappings, jobs and monitoring. Install a compatible provider connector to communicate with an external platform. You can get Magento Connector for Odoo here:
https://apps.odoo.com/apps/modules/19.0/odoo_ecommerce_magento

Can I use Core with more than one store or company?

The framework supports multiple Stores with company-scoped records and access controls. Configure each Store within the correct company.

What handles long-running imports and exports?

OCA queue_job processes background work. The connector implements the platform-specific operations and determines supported resources.

Are all import and export operations available without a connector?

No. Import, Export and Update depend on the capabilities implemented by the installed provider connector.

Where can I find synchronization errors?

Review Queue Jobs, Synchronization Issues and Synchronization States in the eCommerce menus.
